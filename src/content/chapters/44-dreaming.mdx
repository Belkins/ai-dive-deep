## Four pieces, and the model only touches one

{/* [VLAD: voice the walk through the four pieces. Factual skeleton you can lean on:
   1. SELECT — pick recent sessions deterministically: skip the LIVE/newest one (still being written) and any already-dreamed (a ledger keyed on mtime+bytes). Window + cap (default 5 sessions / 7 days). Never "all."
   2. DIGEST — a plain Python pass turns a 5.8 MB session .jsonl into ~24K chars by keeping human prompts + assistant prose and dropping the tool plumbing. This happens OUTSIDE the agents because a 5 MB transcript cannot enter an agent — that's Rule 5: code answers, the model judges.
   3. EXTRACT — read-only Explore agents fan out, one per session. Each candidate MUST cite a verbatim quote. The agents are propose-only; they structurally cannot write.
   4. VERIFY — the load-bearing gate. Re-grep each cited quote against the RAW .jsonl (not the lossy digest the agent read). Real quotes survive; invented ones drop.
   Then it writes a dated review file and updates the ledger. It never touches memory/.] */}

{/* ───────────────────────── BEAT 6 — THE THESIS ──────────────────────── */}
## Memory tools don't crash. They get abandoned.

{/* [VLAD: the closing law. Memory-hygiene tooling doesn't die in a crash — it dies by quiet abandonment, surfacing nothing useful until you stop running it. So it ships with a yield-floor tripwire: three consecutive runs that surface zero NEW candidates and it prints "DREAM IS PROPOSING NOTHING — extractor may be mis-tuned or the corpus is saturated," which turns abandonment into a decision instead of a drift. And auto-write is EARNED, not assumed: only after the frontmatter is normalized to one schema, the ledger is proven stable, and ~30 days of accept/reject data show the extractor is right ≥ 80% of the time. Tie back to the four Anthropic manifestations — the industry is converging on walk-away autonomy; the discipline is knowing which job you don't hand it yet. The loop pointed at the agent's own memory is that job.] */}
