Principles

The ten rules the whole system obeys. Express hierarchy with size, serif-vs-sans, and the single accent — never weight or shadow.

01 · Dark-first

:root is the dark theme. Light is a 5-of-7-var override. Design on near-black first.

02 · One hot accent

Flame is the only warm accent — links, primary CTA, focus, numerals. If everything's orange, nothing is.

03 · Mono = machine

Serif = author, sans = reader, mono = the machine talking. Set commands & read-outs in mono.

04 · Green = system state

Flame = what you do; terminal-green = what the system knows. Don't cross the wires.

05 · Generous measure

Prose lives in a fixed 760px column, 17px, line-height 1.75. Reading is the core UX.

06 · Restraint over ornament

Headings always 500, hairline borders, modest radii, no shadows.

07 · Motion is an accent

Three entrances + one 150ms micro-transition. Nothing bounces or parallaxes.

08 · Warm neutrals

The ramp is warm "ink", never #000/#888/#fff. Warmth makes it feel like paper.

09 · Accessible by default

Focus rings, skip-link, reduced-motion, print — requirements, not extras.

Tailwind's 4px scale, used tight. Empirically it clusters into micro / component / block / section tiers.

Drift & backlog

The system is coherent at the token level but drifted at the application level. Top items to standardize — full list in the spec.

  • H1 · Add semantic color utilities (text-accent, bg-paper, border-line) → kill the 999 inline style= attrs.
  • H2 · The numbered ink/flame/terminal palette is ~95% dead (0 uses) — delete or adopt.
  • H3 · Standardize the eyebrow: ~108 ad-hoc labels across 9 sizes × 9 trackings → one .eyebrow class.
  • H4 · Add --success/--warning/--error/--info + a --chart-* ramp; replace raw status hexes.
  • H5 · Replace hard-coded #FF6B2C/#22d3a0/#aaa79a in ~9 widgets with tokens.
  • M1–M3 · One card radius (rounded-xl); consolidate the pill (~10 reimplementations); collapse 3 reading widths → 760px.
  • L6 · Decide on lucide-react — delete the dead dependency or adopt with the 24/currentColor/stroke-2 conventions.
