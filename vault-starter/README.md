# Vault Starter — Operating an OS, Continued

This is a working Obsidian vault. Drop it in, point Obsidian at the folder,
install the 8 plugins below, run for two weeks. By month three the graph
fires like a brain.

Companion to the chapter [The Vault — Obsidian as Working Memory](https://belkins.github.io/ai-dive-deep/chapters/04-the-vault) in
*Ultimate AI Dive Deep* by Vlad Podoliako.

## What's inside

```
.
├── CLAUDE.md                  # working memory, read on every AI session
├── 00-Inbox/                  # dump zone for raw capture
├── 01-Daily/                  # daily notes, YYYY-MM-DD.md
├── 02-Projects/
│   ├── Active/                # any entity with state + lifecycle
│   └── Archive/               # cold projects
├── 03-People/                 # one file per recurring human
├── 04-Companies/              # portfolio entities
├── 05-Newsletter/             # drafts, ideas, published
├── 06-References/             # links, papers, evergreen notes
└── 99-Templates/              # Templater-driven scaffolds
```

## Setup (15 minutes)

1. **Install Obsidian** — https://obsidian.md (free)
2. **Open this folder as a vault** — Obsidian → Open folder as vault
3. **Install community plugins** (Settings → Community plugins → Browse):
   - Templater
   - Dataview
   - Calendar
   - Periodic Notes
   - Tag Wrangler
   - Tasks
   - Excalidraw
   - Advanced Tables
4. **Point Templater at 99-Templates/** (Settings → Templater → Template folder)
5. **Sync setup** — iCloud (Mac/iPad) is free, encrypted, works. Obsidian Sync
   ($8/mo) is cross-platform end-to-end-encrypted. Dropbox works on free but is
   not encrypted at rest.
6. **Edit CLAUDE.md** — fill in your Me / People / Active Projects / Preferences

## What to do day 1

- Drop your last 50 captured thoughts into 00-Inbox/ as quick `.md` files
- Write today's daily note (Calendar plugin makes this one click)
- Pick the one company / person / project you spend the most time on this week → create the note in `04-Companies/`, `03-People/`, or `02-Projects/Active/`
- Quit Obsidian, drink water

## What to do week 1

- Daily capture in 00-Inbox (5 min/day)
- Friday 20-min review: move Inbox items to permanent homes
- Don't try to perfect the structure. Let it grow.

## What to do month 3

- Run the graph view. Look for: dense central cluster (good — your themes are firing), orphan ring (need linking passes), disconnected clusters (themes you've abandoned)
- Re-read CLAUDE.md and update it
- Add the AI integration (filesystem MCP pointed at vault root)
